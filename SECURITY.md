# Política de segurança

Este projeto é **educacional e não foi auditado**. Não use em mainnet com valores reais sem uma
auditoria profissional.

## Reportando vulnerabilidades

Encontrou uma falha? **Não abra uma issue pública.** Use a aba *Security → Report a vulnerability*
do repositório no GitHub (ou contate o mantenedor em privado). Descreva o problema, o impacto e,
se possível, um teste que o reproduza.
